# 車機音樂盒（CarMusicYT）— 路瑞寶 6350 + Foxtron CAVIRA 直立螢幕專用

專為 **路瑞寶 6350 安卓盒** 搭配 **Foxtron CAVIRA 直立大螢幕** 打造的 YouTube 音樂類型點播播放器：
- **一鍵選類型即播**：內建「流行華語」、「台語流行」、「台語經典」、「國台語金曲」、「懷舊國語老歌」、「西洋流行」、「韓樂 K-POP」、「華語排行榜」8 大公開 YouTube 歌單，也可點右上 **`+`** 貼上任意 YouTube / YouTube Music 歌單網址擴充。
- **真正不間斷、不重複播放**：擷取完整 YouTube 歌單曲目後於本機建立隨機洗牌佇列並持久化記錄已播 ID，單首結束自動無縫接下一首、遇受限影片自動秒跳，直到整份歌單全數聽完才重新洗牌。
- **背景續播＋方向盤控制**：覆寫車機背景 WebView 可見性並搭配 `MusicKeepAliveService` 前景服務，切去開導航不斷音，支援方向盤上一首／下一首／暫停鍵。
- **可切換 MV 預覽／純聽歌模式**：點右上攝影機圖示即可隱藏影片畫面、保留完整音訊播放，開車更專心。
